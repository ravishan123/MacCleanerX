### Install

1. Download **`MacCleaner-<version>.dmg`** below.
2. Open it and drag **Mac Cleaner** onto **Applications**.
3. First launch: macOS blocks apps that aren't notarized. Open **System Settings → Privacy & Security** and click **Open Anyway** ([step-by-step guide](https://github.com/ravishan123/MacCleanerX/blob/main/docs/USER_GUIDE.md#first-launch-open-anyway)).
4. Give it **[Full Disk Access](https://github.com/ravishan123/MacCleanerX/blob/main/docs/USER_GUIDE.md#full-disk-access)** so it can check every folder.

Requires macOS 14 Sonoma or later, Apple silicon or Intel. Verify the download with `shasum -a 256 -c MacCleaner-<version>.dmg.sha256`.
